# Binance 24 小时成交额门槛配置设计

## 目标

将 Binance USDⓈ 永续合约 24 小时成交额门槛从固定常量改为可配置参数。默认值保持 500 万 USD，服务器可在 `.env` 中使用 `5M` 这类简写自定义。

## 配置接口

- 环境变量：`BINANCE_MIN_TURNOVER_USD=5M`。
- 可选命令行参数：`--binance-min-turnover-usd`，优先级高于环境变量。
- 未配置时默认使用 `5M`。
- 修改配置后需要重启服务生效。

## 数值格式

- 支持不带单位的非负有限数字，例如 `5000000`。
- 支持大小写不敏感的 `K`、`M`、`B` 后缀，分别代表千、百万、十亿。
- 支持小数，例如 `7.5M`、`0.02B`。
- 允许首尾空白，但不接受内部空白、逗号、额外字符、负数、`NaN` 或无穷值。
- 非法配置在启动参数解析阶段直接报错，不回退到默认值。

## 数据流

1. 启动参数解析器读取命令行参数或 `BINANCE_MIN_TURNOVER_USD`。
2. 专用解析函数把简写转换为 USD 数值并完成严格校验。
3. `MonitorApplication` 保存该数值，并显式传给 Binance 币种池加载函数。
4. Binance 解析器仅保留 `quoteVolume >= 配置值` 的正常交易 USDT 永续合约。
5. `/api/summary` 返回当前实际门槛，前端据此动态展示筛选说明。

配置值不会由数据源模块自行读取环境变量，避免隐藏依赖并保证测试可控。

## 页面与文档

- 页面表格底部按当前配置显示易读金额，例如 `500 万 USD`、`1,000 万 USD`。
- `.env.example` 增加 `BINANCE_MIN_TURNOVER_USD=5M` 及单位说明。
- README 说明支持的简写格式、默认值和重启要求。
- 15 分钟 K 线成交额突破均量条件不变。

## 测试

- 覆盖纯数字、大小写后缀、小数后缀和零值。
- 覆盖负数、非数字、`NaN`、无穷值、未知后缀、内部空白和逗号。
- 验证自定义门槛准确控制 Binance 币种池边界。
- 验证应用把配置传给数据源，并在摘要中返回实际值。
- 验证前端显示 API 返回的门槛，不再硬编码 500 万。
